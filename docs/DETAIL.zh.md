# CARSI 文献浏览器

用一台**专用 Chrome**（独立配置 + 本地调试端口）承接学校的机构授权，让 DSH 在订阅数据库里检索、
下载、校验全文，而不是只拿到 OA 副本或预印本。

## 能做什么

| 工具 | 作用 |
|---|---|
| `papers_search` | 在指定库检索，返回结构化记录，并标注每条能否全文访问 |
| `papers_fetch` | 下载一篇 PDF，校验字节与页数，按 `年份-一作-题名.pdf` 落盘并记审计 |
| `papers_access` | 打开出版社页面，报告机构身份 / 付费墙 / 人机验证状态 |
| `papers_login` | 打开机构登录入口，把窗口交给你完成 CARSI 登录 |
| `papers_status` | 浏览器是否在跑、端口、配置目录、已开标签 |
| `papers_open` / `papers_eval` | 打开任意页面 / 在页面里执行 JS（未适配库的兜底） |

已内置适配：IEEE Xplore、Springer Nature Link、ScienceDirect。新增一个库只要在
`lib/papers.js` 的 `ADAPTERS` 里加一个对象（检索、取 PDF、记录页 URL、元数据）。

## 授权与合规

- **登录永远由你完成**：插件不代填、不保存、不回放任何凭据。遇到 CARSI 登录页或人机验证时，
  它会弹系统提醒、把浏览器窗口提到前台，然后最多等 90 秒，你点完自动继续。
- **只取你已订阅的内容**：付费墙和验证码只被如实报告，不会被绕过。
- **下载要校验**：必须是 `%PDF-` 开头，页数优先用 `pdfinfo` 统计；把付费墙页面存成 `.pdf` 会被拒绝。
- **限速与上限**：请求间隔默认 1500 ms，单进程最多下载 30 篇；每次检索/下载都写入
  `carsi-audit.jsonl`。

## 安装

```sh
dsh plugin --profile <profile> add /绝对路径/dsh-carsi-papers
```

或在 **插件 → 添加插件** 里选择本目录。插件自带浏览器驱动，不需要额外依赖，也不需要构建。

## 已知限制

- 独立配置意味着每个库第一次访问可能要手动登录一次；出版社会话过期后同理。
- 人机验证只能由人完成——插件负责提醒和等待，不负责点掉它。
- IEEE 页面没有 Highwire 元数据标签，文件命名依赖检索时缓存的记录。
- `papers_eval` 拥有该会话的全部能力，属于诊断工具，不是沙箱。
